# משחק שליח – Pizza 4 The People (שלד)

**איך מריצים במחשב:** לחיצה כפולה על index.html (נפתח בכרום). צריך אינטרנט – Three.js ומנוע הפיזיקה cannon-es נטענים מ-CDN.
חיצים / WASD = נהיגה, רווח = בלם. עוצרים בתוך העיגול הצהוב = משלוח.

## מה יש עכשיו
- פיזיקה אמיתית (cannon-es): 20 מגשי פיצה, כל אחד גוף נפרד עם משקל וחיכוך, מוערמים על ארגז שזז עם האופניים. פנייה חדה, בלימה או מכה בקיר – והערימה גולשת ומתפרקת באמת.
- רטט בנייד על כל פיצה שנופלת (navigator.vibrate – עובד באנדרואיד; אייפון לא תומך ברטט מדפדפן).
- מסירה: לעצור בתוך העיגול. תשלום 10₪ + טיפ שמתחיל ב-25₪ ויורד בשקל לשנייה. מוסרים את הפיצה העליונה.
- בלי רמות קושי. המשמרת נגמרת כשאין יותר פיצות על הארגז.
- מצלמה מאחור בסגנון GTA, הגה רך, השכבה בפניות, רעידת מצלמה במכות.
- עיר פלייסהולדר. בניינים הם גם קירות פיזיקליים.

## לחבר בהמשך
- מפת יפו: לייצא מ-Blender כ-GLB (File → Export → glTF 2.0, פורמט .glb), לשים בתיקייה assets, ולמלא `CFG.MAP_URL = 'assets/jaffa.glb'` בראש הקוד. (קובץ מקומי דורש להריץ דרך שרת, נסדר כשנגיע.)
- מודל אופניים: `CFG.BIKE_URL`.
- תחושה: TRAY.friction (חיכוך בין מגשים), MAX_LAT_ACC (כמה חדה פנייה מלאה), STEER_SMOOTH.
- נייד: ההטיה עובדת רק בקישור HTTPS – נעלה את המשחק לקישור בשלב הבא.
