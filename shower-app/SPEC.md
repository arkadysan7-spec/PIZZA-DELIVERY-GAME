# אפיון – אפליקציית הדמיית מקלחונים (PWA)

## מטרה
איש מכירות/מתקין מצלם את חדר הרחצה אצל הלקוח, בוחר מקלחון מהקטלוג של העסק, מסמן איפה הוא יותקן,
ומקבל תוך כדקה הדמיה פוטוריאליסטית שאפשר לשלוח ללקוח בוואטסאפ. כל ההדמיות נשמרות לפי לקוח.

## משתמשים
- **משתמש עיקרי:** בעל העסק / סוכן / מתקין, בטלפון, בשטח.
- **לקוח קצה:** מקבל תמונה בוואטסאפ. לא משתמש באפליקציה.

## זרימה ראשית
1. **לקוח** – בחירת לקוח קיים או יצירת חדש (שם, טלפון, כתובת).
2. **צילום** – מצלמה אחורית (`capture=environment`) או גלריה. הקטנה בצד הלקוח ל-2048px ותיקון כיוון (EXIF).
3. **מוצר** – קטלוג מהאתר: שם, תמונות, מידות, עובי זכוכית, גימור (שחור מט / כרום / ניקל). בחירת גימור ועובי.
4. **מיקום ופרזול** – גרירת 4 פינות על התמונה (מישור הזכוכית), צד המחיצה הקבועה, רוחב/גובה/רוחב דלת, ועוד:
   - קיבוע המחיצה: **זוויות קיר 90°** (למעלה ולמטה, מבחוץ רואים רק מרובע קטן) / **פרופיל U 1×1 ס"מ** בקיר / בקיר וברצפה.
   - **מייצב** – ללא / לקיר / לתקרה.
   - **דלת עם צירים** – ציר זכוכית-זכוכית או קיר-זכוכית, פתיחה החוצה.
   - **שיפוץ** – אופציונלי: חיפוי קירות חדש / ריצוף חדש (סגנון לבחירה).
   - סקיצה חיה מצוירת מעל התמונה כבר בשלב הזה (חינם, מיידי).
5. **הדמיה** – שליחה לשרת → מודל תמונה (Nano Banana Pro ברירת מחדל, GPT Image חלופה), איכות high, 2K.
6. **תוצאה** – השוואת לפני/אחרי (סליידר), הורדה, שיתוף בוואטסאפ, נשמר בהיסטוריית הלקוח.

## שמירה על התמונה המקורית (הנדסת פרומפט)
המודל מקבל 3 תמונות: (1) המקור, (2) סקיצת מיקום על המקור, (3) תמונת המוצר מהקטלוג.
הפרומפט מחייב: אותה מצלמה/פרספקטיבה/חיתוך/יחס, אסלה/כיור/ברזים/ניקוז/חלון במקומם, ללא הוספה או הזזה,
ללא שרידי סקיצה. פרזול מתואר במדויק (מידות, גימור אחיד, מה רואים מבחוץ). רינדור ב-aspect ratio של המקור.

## ארכיטקטורה
```
טלפון (PWA, RTL)                 Vercel
 ├ index.html / app.js     ───►  /api/config   – אילו ספקים מוגדרים, האם נדרש קוד גישה
 ├ IndexedDB: לקוחות+הדמיות ───►  /api/catalog  – גריפת האתר (Shopify / WooCommerce / JSON-LD / sitemap), cache 6 שעות
 └ Service Worker (offline)  ───►  /api/render   – בניית פרומפט + קריאה למודל, מפתח API רק בשרת
                                         └ Vercel Blob (אופציונלי) – קישור ציבורי לתמונה לוואטסאפ
```
- **מפתחות API** רק במשתני סביבה ב-Vercel. הדפדפן לא רואה אותם.
- **קוד גישה** (`APP_ACCESS_CODE`) – כל קריאה ל-API דורשת אותו, כדי שזרים לא ישרפו קרדיט.
- **SSRF** – השרת מושך תמונות מוצר רק מהדומיין של האתר ומ-CDN מורשים.
- **מגבלות Vercel** – גוף בקשה/תגובה עד 4.5MB: התמונה נדחסת בצד הלקוח, והתוצאה מומרת ל-JPEG בשרת (sharp).

## גריפת קטלוג
סדר ניסיונות: Shopify `/products.json` → WooCommerce Store API `/wp-json/wc/store/v1/products` →
sitemap + JSON-LD/OpenGraph בדפי מוצר. חילוץ: מידות (`80x190`, `רוחב 80-120`), עובי זכוכית (`8 מ"מ`),
גימור (שחור מט/כרום/ניקל/זהב/נירוסטה מוברשת). אם אין התאמה – קטלוג הדגמה.

## שליחה בוואטסאפ
1. **Web Share API עם קובץ** (אנדרואיד/אייפון) – נפתח גיליון שיתוף, בוחרים וואטסאפ → הלקוח. התמונה נשלחת עצמה.
2. **wa.me לטלפון הלקוח** – הודעה מוכנה; אם Vercel Blob מוגדר, כוללת קישור לתמונה.

## אב-טיפוס (גרסה זו) – מה כלול
- כל הזרימה למעלה, היסטוריה מקומית במכשיר, מצב הדגמה (mock) כשאין מפתח API.
## שלב הבא
- סנכרון היסטוריה לענן (Postgres/Blob) + כמה משתמשים.
- מקלחון פינתי/מחומש (שני מישורים), סימון אוטומטי של קירות/רצפה (segmentation).
- הצעת מחיר אוטומטית מהקטלוג, לוגו העסק על התמונה, ריבוי וריאציות (3 גימורים במכה).
- ממשק ניהול קטלוג (תיקון ידני לנתונים שנגרפו).
