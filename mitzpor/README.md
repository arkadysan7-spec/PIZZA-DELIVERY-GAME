# ליל המצפור · OBSESSION

שיחה קולית של דקה עם **נוגה**, השומרת של המצפור. היא מתקשרת אליך, יודעת דברים שהיא לא אמורה לדעת, לוקחת ממך את האובססיה שלך כ"כרטיס כניסה", ושולחת לך פוסטר אישי לאירוע.

## איך זה עובד

1. **"להיכנס"**: לחיצה אחת שמאשרת מיקרופון ופותחת סאונד.
2. **הטלפון מצלצל.** בזמן הצלצול החיבור כבר נפתח ברקע, אז כשעונים היא מדברת מיד. אפשר גם לדחות. היא תתקשר שוב, ובפעם השלישית "תפרוץ" לשיחה לבד.
3. **השיחה, עד דקה:**
   - **פתיחה מאמצע סצנה.** היא מתווכחת עם הדי-ג׳יי, סופרת כוכבים, או לוחשת כי מישהו נרדם. בכל שיחה מוגרלת סצנה אחרת.
   - **"מהמצפור רואים הכל".** היא יודעת כמה זמן נתתם לטלפון לצלצל, אם ניתקתם לה, מה השעה, כמה סוללה נשארה, ואם כבר דיברתם איתה פעם (ואז היא זוכרת את השם ואת האובססיה).
   - **האובססיה.** "כדי לעלות למצפור צריך להשאיר אצלי אובססיה", עם טוויסט מוגרל: ניחוש מצחיק, ספירה לאחור, סוד משלה, צליל של האובססיה.
   - **ההזמנה והמילה הסודית**, ופרידה.
4. **הפוסטר.** בגודל סטורי, עם השם, האובססיה, ציטוט שלה עליכם, חותמת עם המילה הסודית, ופרטי האירוע. אפשר לשתף או לשמור.

## הרצה מקומית

צריך Node 20 ומעלה. אין תלויות, אין `npm install`.

```bash
cd mitzpor
cp .env.example .env      # ולמלא OPENAI_API_KEY
node server.js            # http://localhost:3000
```

- `?demo=1`: קפיצה ישר לפוסטר לדוגמה (עובד גם בלי מפתח)
- `?debug=1`: יומן אירועים חי בתחתית המסך

> מיקרופון בטלפון עובד רק ב-**HTTPS**. כדי לבדוק מהטלפון מול המחשב: `npx localtunnel --port 3000` או ngrok.

## העלאה לאוויר (Render)

הקובץ `render.yaml` נמצא בשורש הריפו. ב-Render: **New → Blueprint**, בוחרים את הריפו, ממלאים `OPENAI_API_KEY`, וזהו.
כל שרת Node אחר עובד באותה צורה: `node server.js` עם משתנה הסביבה.

## מה לערוך

| קובץ | מה יש בו |
|------|----------|
| `event.json` | **כל פרטי האירוע**: תאריך, שעה, מקום, ליינאפ, קישור לכרטיסים, פוסטר רשמי. שדה ריק = היא לא מזכירה אותו והפוסטר מדלג עליו. נקרא מחדש בכל שיחה, בלי הפעלה מחדש |
| `lib/prompt.js` | האופי של נוגה, מבנה הדקה, הסצנות והטוויסטים |
| `.env` | מודל, קול (`marin` / `cedar` / `shimmer`...), מהירות דיבור, אורך שיחה, מגבלות |
| `public/poster.js` | עיצוב הפוסטר |
