## איך מוצאים בעיות אחרי שיחות אמיתיות

```
LOG_CALLS=1 node server.js     # התמלילים נשמרים
node tools/check-calls.js      # דוח: שאלות חוזרות, מונולוגים, חריגות, פתיחה איטית, שיחות בלי שם
```
ובזמן שיחה אפשר לפתוח `?debug=1` ולראות את כל האירועים בתחתית המסך.
